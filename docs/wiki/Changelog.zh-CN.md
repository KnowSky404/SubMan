# 变更记录

按时间倒序记录有意义的产品、维护和迁移变化，中英文在同一提交中更新。
这里记录仓库变更；生产部署和真实服务验收需另有验证证据。

## 未发布

### 2026-10-31 - 显式设备重置与重新连接

- 在设置中增加需确认的恢复入口，支持原 Gist 已删除或不可访问、退出登录和云端加载失败的场景。
- 以事务清除当前绑定、本机业务缓存和当前完整队列；保留历史队列与隔离证据，
  正在发送或并发变化时拒绝重置，旧标签页不能恢复已放弃的绑定。
- 重置仅作用于本地，存储提交后才清除认证；用户再次连接时才加载云端或初始化空工作区。

### 2026-10-31 - Gists 文件页面改为只读

- 所有类型的 Gist 文件均只读，移除输出删除和过期引导标记清理按钮及处理逻辑；
  保留刷新、文件链接、复制链接、文件分类和引导状态提示。
- 增加中英文说明，引导到聚合或客户端导出页面管理发布，并通过浏览器测试验证
  查看和刷新文件不会提交云端变更。已有修复状态仍需单独排查。

### 2026-10-28 - Primer 界面与交互系统

- 按已确认的 GitHub 风格概念稿统一六个页面：明暗主画布、更清楚的页面标题、
  开放式筛选栏、单层资源表头、随内容自然增高的首页分栏，以及一致的编辑与发布布局。
- 增加共享弹层、复制确认、异步操作反馈、导航指示线、展开和进出场动效，
  并统一适配减少动态效果偏好；手机编辑采用固定操作栏的无障碍底部弹层。
- 继续以云端确认为准：等待、重试、阻塞和确认不确定时保留草稿，
  仅在远端提交确认后显示成功反馈。
- 修复自动主题在首屏及系统偏好变化时未应用页面颜色的问题，显式明暗选择继续优先。
- 对外 API、Workspace 结构、持久化和投递协议保持不变。


### 2026-10-27 - 页面层级与交互优化

- 区分可返回首页的品牌工具栏与业务导航，统一页头和正文对齐；增加可见的云端状态、
  支持悬停和键盘聚焦的图标提示、主题菜单键盘操作及小屏导航翻页入口。
- 恢复暗色主按钮的强调色，提高列表辅助信息可读性；删除重复的新建入口和状态信息，
  修复搜索图标间距、区分空数据和筛选无结果，增大触摸按钮并让可用文件名成为真实链接。
- 首页根据已有数据展示最近资源和已确认的发布信息，空工作区保留入门指引；
  聚合页收纳高级配置并说明保存、预览、目标与发布的关系，云端写入协议保持不变。
- 补齐相关界面的中文标签并本地化资源更新时间；复用浏览器测试数据，按用例隔离截图。
