# Historical design records

This directory preserves dated plans and specifications as implementation evidence.
These records may describe retired workflows. Use the maintained
[English Wiki](../wiki/Home.md) or [中文 Wiki](../wiki/Home.zh-CN.md) for current behavior.

- `specs/`: dated product and protocol designs.
- `plans/`: implementation plans and verification notes.
- Protocol decisions that remain open live in [ADR](../adr/0001-workspace-v2-deferred-protocols.md).

Keep historical records dated. Put new release and development summaries in the
bilingual [changelog](../wiki/Changelog.md), with its [Chinese counterpart](../wiki/Changelog.zh-CN.md).
